# ヘアカルテ

**公開サイト: https://kyosuke0306.github.io/hair_karte/**

美容院で「前回どう注文したか」を思い出せなくなる問題を解決するための、髪型カルテ Web アプリです。
ヘアスタイル名称・バリカンのミリ数・自己評価・参考モデル / 自分の写真、そして「いつ・どこで切ったか」を 1 件のカルテとして記録します。

ビルド不要のプレーンな HTML / CSS / JavaScript 製で、データはすべて端末内（IndexedDB）に保存されます。サーバーには何も送信されません。

## 主な機能

### 1. 髪型の注文の記録
- ヘアスタイル名称（よく使う名称は入力候補から選択可）、仕上がりの長さ感
- サイド / バック / もみあげ の **ミリ数**、刈り上げの高さ、トップ・前髪の長さ
- すき具合（量感調整）、パーマ、カラー、スタイリング剤
- 美容師さんに伝えたことをそのまま書ける「注文メモ」
- **注文シート**：入力内容を美容室で読み上げられる文章に自動整形。ワンタップでコピーできます

```
【スタイル】ツーブロック × マッシュショート（ショート）
【刈り上げ】サイド 6mm / バック 3mm→9mmグラデ / もみあげ 6mm / 刈り上げの高さ 耳の高さまで
【長さ】トップ 6cm・指2本分残す / 前髪 眉が半分隠れる長さ
【その他】量感 少なめにすく / カラー 8トーン アッシュベージュ
【伝えること】サイドは刈り上げて、トップは動きが出るようにレイヤーを入れてください。
【次回はこうしたい】次はトップを2cm長めに残してもらう
```

### 2. 自己評価
- 星 5 段階の満足度（同じ星をもう一度押すと未評価に戻ります）
- よかった点 / いまいちだった点 / 次回はこうする

### 3. 写真
- **参考モデル**と**自分（仕上がり）**を分けて、それぞれ複数枚保存
- スマホでは「画像を選ぶ / 撮影」からその場で撮影も可能
- 保存時に長辺 1600px へ自動縮小（＋サムネイル生成）するので、容量を圧迫しません
- タップで全画面表示

### 3-1. 顔隠し
写真の「顔を隠す」ボタンから、顔をモザイク・ぼかし・ぬりつぶしで隠せます。

- **自動検出**：ブラウザに顔検出機能があればそれを使い、無い端末では肌色領域を解析する
  簡易検出にフォールバックします。誤検出もあるため、結果はそのまま確定せず必ず確認できます
- **手動**：画面を指でなぞった範囲を隠せます。タップでも定型サイズで置けます
  （置いた場所をもう一度タップすると消えます）
- 形は「丸 / 四角」、隠し方は「モザイク / ぼかし / ぬりつぶし」から選べます
- 「適用」を押すと**画像そのものに焼き込まれます**。元の顔は画像データから消えるため、
  エクスポートしたファイルや共有した画像にも顔は残りません（元に戻すことはできません）
- すべて端末内の処理で完結し、画像が外部に送信されることはありません

### 4. いつ・どこで切ったかの記録
- カットした日・お店の名前・店舗 / エリア・担当スタイリスト・料金
- 一度入力したお店や担当者は次回から入力候補に出ます
- トップに「◯日前にカット」「平均周期」「次のカットの目安日」を表示

### 5. ふりかえり（記録タブ）
- カット回数 / 前回から / 平均周期 / 平均満足度 / 合計金額 / 平均単価
- カット間隔の推移グラフ（直近 12 回）
- よく行くお店ランキング、評価の高かったスタイルランキング

### 6. その他
- 「この内容で新規」：前回のカルテを複製して新しいカルテを作成（参考モデルの写真も引き継ぎ）
- スタイル名・店名・メモの横断検索、並べ替え（新しい順 / 古い順 / 評価順）
- JSON でのエクスポート / インポート（写真を含む完全バックアップ）
- ライト / ダークテーマ、PWA としてホーム画面に追加可能・オフライン動作

## 使い方

公開サイト <https://kyosuke0306.github.io/hair_karte/> をブラウザで開けばそのまま使えます。
スマホではブラウザのメニューから「ホーム画面に追加」すると、アプリのように全画面で起動します。

ローカルのファイルからも動きます。`index.html` をブラウザで開くだけです。ただし PWA（ホーム画面に追加・オフライン動作）を有効にするには、
HTTP(S) 経由での配信が必要です。

ローカルで動かす場合:

```bash
cd hair_karte
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

main ブランチへの push で、`.github/workflows/pages.yml` が GitHub Pages へ自動デプロイします。

## データについて

- カルテと写真は、開いたブラウザの **IndexedDB** にのみ保存されます。外部送信は一切ありません。
- そのため、**ブラウザのデータを消去すると、カルテも消えます**。
  機種変更前やデータ消去前には、設定タブから必ずエクスポートしてください。
- プライベートブラウジングでは保存されない場合があります。

## ファイル構成

```
index.html      画面の骨組みと各ビューのテンプレート
styles.css      デザイン（ライト / ダーク対応）
js/db.js        IndexedDB ラッパー（records / photos ストア）
js/photos.js    画像の縮小・サムネイル生成・Blob 変換
js/mask.js      顔隠しエディタ（自動検出・手描きマスク・焼き込み）
js/app.js       ルーティング、各画面の描画、フォーム処理、集計
sw.js           オフライン用 Service Worker
.github/workflows/pages.yml   GitHub Pages への自動デプロイ
manifest.json   PWA マニフェスト
icon.svg        アプリアイコン（櫛をかたどったロゴ）
```

## 対応ブラウザ

IndexedDB と Canvas が使える最近のブラウザ（iOS Safari / Android Chrome / デスクトップ各種）。
外部ライブラリやビルドツールは使用していません。

## デザインについて

アイコンはすべて自前の SVG（`index.html` 内のスプライト）で、絵文字は使っていません。
`currentColor` で描いているため、ライト / ダークテーマや文字色にそのまま追従します。
アプリアイコンは櫛をかたどったシンプルなロゴです。
