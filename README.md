# ヘアカルテ

**公開サイト: https://kyosuke0306.github.io/hair_karte/**

**美容師さんに髪型の注文を正しく伝えるためのアプリです。**

「いつもの感じで」が通じない初対面の美容師さんにも、どこを何ミリにしたいのかが
一目で伝わる**注文シート**を作って保存し、その場で自分の口で伝えるか、画面をそのまま見せられます。

いつ・どこで切ったかの記録（カルテ）は、注文シートを育てるための付属機能です。

ビルド不要のプレーンな HTML / CSS / JavaScript 製で、データはすべて端末内（IndexedDB）に保存されます。サーバーには何も送信されません。

## 画面構成

下部のタブで5つの画面を切り替えます。

| タブ | 役割 |
| --- | --- |
| 注文シート | **このアプリの中心。**髪型の注文をここで作り、美容師さんに伝える / 見せる |
| カルテ | いつ・どこで切ったかと、そのとき使った注文シート・写真・評価を残す（付属） |
| スタイリング剤 | いま使っているもの／使ってみたいものを分けて残す |
| 記録 | カット間隔や満足度などのふりかえり |
| 設定 | バックアップ・テーマ・データの削除 |

## 主な機能

使う流れは次の通りです。

1. **注文シート**タブで髪型の注文を作る
2. 美容室で「伝える文章」を読む、または「見せる」で画面を渡して切ってもらう
3. **カルテ**タブに、切った日・お店と**使った注文シートを貼り付けて**記録を残す

髪型の注文を作れるのは注文シートタブだけです。カルテタブでは作らず、
作ったシートを貼り付けます（貼り付けた内容はカルテに写しとるので、
あとでシートを直しても過去の記録は変わりません）。

### 1. 髪型の注文（部位図）
ヘアスタイル名称は長さ別にまとめた**選択式**です（一覧に無いものは「その他」で自由に入力でき、
一度使った名前は次回から候補の先頭に出ます）。

中央にアバターを置き、部位ごとの指定を吹き出しで表示します。文字を読まなくても、
どこを何ミリにしたかがひと目で分かります。

- **正面図**：トップ / 前髪 / サイド / もみあげ
- **横・後ろ図**：バック / 刈り上げの高さ（高さは破線で位置を示します）
- 指定済みの部位は髪が色づき、未設定の部位はベースの色のまま残ります
- 部位をタップすると選択シートが開きます
  - **ミリ数はスライダーで選びます**（0.5 刻み、0 は「刈り上げなし」）。
    −／＋ボタンでの微調整もできます。ここでボタンとして出るのは
    **自分が使った値の履歴だけ**（新しい順に最大5件）
  - **前髪の長さ・刈り上げの高さなど、数値で表せない項目は候補から選べます**
    （「耳の高さまで」「眉が半分隠れる」など）。一度使った値は次から先頭に出ます
  - どちらもボタンは最大5個。自由入力とクリアも可能です
  - **どんな印象になるかを一緒に出します。**「6mm」と言われても仕上がりが想像しにくいので、
    値に応じた見え方を言葉で添えます
    - ミリ数・長さはスライダーを動かすたびに書き換わります
      （例：6mm →「青みが残る定番の短さ。清潔感のある印象」）
    - 候補から選ぶ項目は、押した瞬間に決まってしまうのでボタンの中に書いてあります
      （例：眉上 →「おでこが出て、明るく元気な印象」）
    - 自由入力でも、ミリ数や決まった言い方なら読み取って表示します
- 名称・長さ感、すき具合 / パーマ / カラー / スタイリング剤、注文メモも記録できます

### 1-1. 美容室で使う2つの画面

注文シートの詳細（カルテの詳細も同じ）に、同じ大きさの2つのボタンを並べています。
どちらの画面もアプリの枠（ヘッダー・タブ・ボタン）を消して内容だけを大きく表示し、
上部のスイッチでその場で行き来できます。表示中は画面が消えません（対応端末のみ）。

**「伝える文章」— 自分の口で伝えるとき（ふだん使う方）**

1行＝1つのお願いに分けて、上から読めばそのまま注文になる文章にします。

```
スタイル          ツーブロック × マッシュショート にしたいです。
サイド            サイドは 6mm でお願いします。
バック            バックは 3mm→9mmグラデ でお願いします。
刈り上げの高さ    刈り上げの高さは 耳の高さまで お願いします。
前髪              前髪は 眉が半分隠れる でお願いします。
伝えたいこと      サイドは刈り上げて、トップは動きが出るようにレイヤーを入れてください。
```

- 文字は 21px の太字。1項目ずつカードに分かれています
- 伝え終わった項目は**タップでチェック**でき、「3 / 6 伝えました」と残りが分かります
- 写真は「最後に写真を見せる」として末尾にまとめます
- 文章はワンタップでコピーできます（LINE などで先に送る用）
- 「耳の高さまで」のように助詞で終わる値は、「まで でお願いします」にならないよう文を整えます

どちらの画面でも、写真は種類ごとに分けて出します。

- **こうしたい（参考の写真）** … 参考モデルの写真
- **切る前** … カルテのみ
- **以前の自分の髪型**（カルテでは**切ったあと（仕上がり）**）… 自分の写真。
  前の髪型を見てもらって、そこからの差を伝えるためのものです

写真が無い枠は出しません。ひとつも無ければ写真の欄ごと出しません。
向きのキャプション（正面 / 横 / 後ろ…）もそのまま表示され、タップで拡大できます。

**「見せる」— 画面をそのまま渡すとき**

- **ヘアスタイル名をいちばん大きく出します**（30px）。美容師さんがまず知りたいところなので、
  「ヘアスタイル」の見出しを付けた枠に入れ、仕上がりの長さ感をその下にタグで添えます
  - シートの名前（「いつもの◯◯」など）は自分用の目印なので、スタイル名と重ならないときだけ
    小さく添えます。スタイル未設定のときはシートの名前が見出しになります
- 部位図の下に、サイド・バック・刈り上げの高さ…と読む順に並べ、値は 20px の太字にします
- **指定していない部位は図にも一覧にも出しません。**渡された側が「未設定」を読まずに済みます
  （自分用のカルテ・注文シートの詳細では、何が空かが分かるよう今まで通り「未設定」と出ます）
- 「お願いしたいこと」と写真も大きく出ます

### 1-2. 注文シート（専用タブ）
髪型の注文内容だけを1枚の雛形として保存できます。**お店の名前・日付・評価・写真は含みません。**

**名前は自動で入ります。**ヘアスタイルを選ぶと「いつもの◯◯」が名前欄に入るので、
毎回タイプせずに済みます。頭に付く言葉は「いつもの / 夏の / 冬の / 短めの / 長めの / きちんとした」
から押すだけで替えられます。自分で書き換えるとそれ以降は自動で触りません
（空にすると、また自動で入るようになります）。

- 部位図・スタイル名称・パーマ / カラー・伝えたいことを、カルテと同じ操作で入力できます
- **写真もカルテと同じ仕様で付けられます**（参考モデル / 自分、向きのキャプション、顔隠し、自動縮小）
- 保存したシートは「伝える文章」で読み上げるか、「見せる」で画面を渡せます
- **カルテへの貼り付け**：カルテの「使った注文シート」で選ぶと、注文の内容と
  **参考モデルの写真**がカルテに入ります（日付やお店はそのまま残ります。
  自分の写真はこれから撮るものなので写しません）
  - 貼り付けた内容は図と一覧で確認できます。「変える」で別のシートに、「外す」で空にできます
  - カルテの詳細には「注文シート「◯◯」」と、どのシートで切ったかが出ます
  - シートを消しても、貼り付け済みのカルテの記録は残ります
- シートの画面からは「このシートでカルテを作る」で新規カルテを開けます

### 2. 自己評価
- 星 5 段階の満足度（同じ星をもう一度押すと未評価に戻ります）
- よかった点 / いまいちだった点 / 次回はこうする

### 3. 写真
- **カルテ**は3つに分けて保存できます
  - **参考モデル** … 注文シートを貼り付けると一緒に入ります
  - **切る前** … 美容室に入る前の髪。仕上がりと見比べられます（注文シートには入りません）
  - **自分（仕上がり）** … 切ったあとの髪
- **注文シート**は「参考モデル」と「以前の自分の髪型」の2つです
- どれも複数枚保存でき、向きのキャプション・顔隠し・自動縮小はすべて同じように使えます
- 登録の方法は3つ：**画像を貼り付け**（クリップボード）/ **画像を選ぶ・撮影** /
  **ドラッグ&ドロップ**（パソコン）。自分で用意した写真ももちろん登録できます
- 写真ごとに**向きのキャプション**を付けられます（正面 / 斜め / 横 / 後ろ /
  トップ（つむじ）/ 全体、自由入力も可）。一覧・拡大表示のどちらにも出ます
- スマホでは「画像を選ぶ / 撮影」からその場で撮影も可能
- 保存時に長辺 1600px へ自動縮小（＋サムネイル生成）するので、容量を圧迫しません
- タップで全画面表示

### 3-1. 参考モデルを探す
「モデルを探す」から、ヘアカタログのサイトを開いて写真を持ち帰れます。

- 検索キーワードは**注文シートの内容から自動で作ります**（スタイル名・仕上がりの長さ感。
  「×」などの記号は検索の邪魔になるので外します）。その場で書き換えられます
- **メンズ / レディース / 指定なし**で絞れます。選んだ区分は次回も覚えています
- 検索先：ホットペッパービューティー / minimo / Instagram / Pinterest / Google 画像検索
- 気に入った写真を長押し（PCは右クリック）して「画像をコピー」→ アプリに戻って
  「画像を貼り付け」で登録できます
- **見つけたページのURL**を貼り付けておくと、その後に貼り付けた写真に「元ページ」への
  リンクが付きます。写真の下・拡大表示・カルテの詳細から開けます

外部サイトの画像をアプリが自動で取ってくることはできません（別ドメインの画像は
ブラウザの制限で読み出せないため）。そのため「コピーして貼り付ける」形にしています。
APIキーは使わず、アプリから自動で外部に通信することもありません。
リンクを押したときにだけ、ブラウザがそのサイトを開きます。

ホットペッパービューティーと minimo は、サイト内検索のURLの形が変わってもリンク切れに
ならないよう、画像検索にサイト指定を付けて開きます。

### 3-2. 顔隠し
写真の「顔を隠す」ボタンから、顔をモザイク・ぼかし・ぬりつぶしで隠せます。

- **自動検出**：ブラウザに顔検出機能があればそれを使い、無い端末では肌色領域を解析する
  簡易検出にフォールバックします。誤検出もあるため、結果はそのまま確定せず必ず確認できます
- **髪型は隠しません。**このアプリでは髪型が主役なので、自動検出は顔の枠をそのまま使わず、
  次の2段階で目・鼻・口のあたりまで絞り込みます
  1. 検出した枠の中の**肌が写っている範囲まで縮める**（髪は肌色ではないので自然に外れます）
  2. そこからさらに上下左右を少し内側に入れる（額や生えぎわを残すため）
  - この絞り込みは内蔵検出でも肌色検出でも共通なので、端末による差が出ません
  - 肌色が十分に見つからなかったときだけ、検出した枠を大きめに削って使います
  - 明るい茶系の髪は肌色と見分けがつかないことがあります。その場合は手描きで調整してください
- **手動**：画面を指でなぞった範囲を隠せます。タップでも定型サイズで置けます
  （置いた場所をもう一度タップすると消えます）
- 形は「丸 / 四角」、隠し方は「モザイク / ぼかし / ぬりつぶし」から選べます
- 「適用」を押すと**画像そのものに焼き込まれます**。元の顔は画像データから消えるため、
  エクスポートしたファイルや共有した画像にも顔は残りません（元に戻すことはできません）
- すべて端末内の処理で完結し、画像が外部に送信されることはありません

### 4. いつ・どこで切ったかの記録
- カットした日・お店の名前・店舗 / エリア・担当スタイリスト・料金
- **Googleマップとの紐付け**
  - 「Googleマップで探す」でお店を検索できます
  - Googleマップの「共有 → リンクをコピー」で得た文字列を貼り付けると、
    店名・座標・リンクを読み取って記録します（短縮 URL の場合はリンクのみ）
  - 記録したお店はカルテの詳細から「Googleマップで開く」で開けます。
    紐付けが無くても、店名での検索リンクを出します
  - 同じお店を次に選んだときは、前回の紐付けを引き継ぎます
  - APIキーは使いません。アプリが自動で外部と通信することはなく、
    地図を開いたときにだけブラウザが Google に接続します
- 一度入力したお店や担当者は次回から入力候補に出ます
- トップに「◯日前にカット」と**前回の日付・お店**、「カット回数」「平均周期」「次のカットの目安日」を表示

### 4-0. 髪質（カルテタブに1つだけ）
髪質はカットのたびに変わるものではないので、**カルテのタブに1つだけ**持ちます。
記録ごとに入れ直す必要はありません。

- 毛量（少なめ / ふつう / 多め）・髪の太さ（細い / ふつう / 太い）・
  かたさ（やわらかい / ふつう / かたい）・くせ（直毛 / 少しうねる / くせ毛 / 強いくせ）
- 気になるところ（いくつでも）：つむじが割れる / 前髪が浮く / 襟足がはねる / ハチが張っている /
  顔まわりが浮く / 広がりやすい / ぺたんとなりやすい / 猫っ毛 / 硬くて収まらない
- すべて押すだけで選べます（もう一度押すと外れます）。選んだ時点ですぐ保存されます
- 一度登録すると畳まれ、見出しに「髪質：毛量 多め ・ …」と要約が出ます
- バックアップにも含まれます

### 4-1. スタイリング剤（専用タブ）
ワックスやバームを、**いま使っている**ものと**使ってみたい・勧められた**もので分けて残せます。

- 種類（ワックス / バーム / クリーム / ジェル / グリース / オイル / スプレー / ムース / パウダー）
- 商品名・ブランド
- **教えてくれた人は名前を打たずに選びます。**カルテに残した担当スタイリストが候補として並ぶので、
  押すだけです（候補が1人もいないときは、この欄自体を出しません）
- **使い心地は書かずに選びます。**毎回文章を書くのは面倒なので、押すだけで決められます
  - セット力：弱め / ふつう / 強め
  - ツヤ感：マット（ツヤなし）/ 自然なツヤ / しっかりツヤ
  - 使ってみて（いくつでも）：伸ばしやすい / 髪になじむ / キープ力がある / 夕方まで持つ /
    ベタつかない / 洗い落としやすい / 香りが好き / 香りが強い / 重たくなる / 夕方に落ちる
  - 同じボタンをもう一度押すと外れます。選んだ内容は一覧のカードにも出ます
  - 文章で残したいときは「ことばでもメモを書く」から書けます（任意）
- パッケージの写真。お店で「これです」と見せられます
- 保存後に「いま使っている」↔「使ってみたい」を切り替えられるので、
  勧められたものを買ったら移すだけです

**商品を探す**：通販・口コミサイトを開いて、商品名や写真を持ち帰れます。

- 検索先：Amazon / 楽天市場 / @cosme / Google 画像検索 / Google 検索
- キーワードは入力済みのブランド・商品名・種類から自動で作ります（未入力なら「ヘアワックス」）
- 参考モデル探しと同じで、**写真はコピーして貼り付け**ます（別ドメインの画像は
  ブラウザの制限で読み出せないため）。ドラッグ&ドロップ・撮影も使えます
- 商品ページのURLを貼り付けておくと、あとからその商品ページを開けます

### 5. ふりかえり（記録タブ）
- カット回数 / 前回から / 平均周期 / 平均満足度 / 合計金額 / 平均単価
- カット間隔の推移グラフ（直近 12 回）
- よく行くお店ランキング、評価の高かったスタイルランキング

### 6. その他
- 「この内容で新規」：前回のカルテを複製して新しいカルテを作成（参考モデルの写真も引き継ぎ）
- スタイル名・店名・メモの横断検索、並べ替え（新しい順 / 古い順 / 評価順）
- JSON でのエクスポート / インポート（カルテ・注文シート・スタイリング剤・髪質・写真を含む完全バックアップ）
- ライト / ダークテーマ、PWA としてホーム画面に追加可能・オフライン動作
- オンラインのときは常に最新を取りに行き、つながらないときだけキャッシュを使います
  （更新したのに古い画面が出続けることがないようにするため）

## 使い方

公開サイト <https://kyosuke0306.github.io/hair_karte/> をブラウザで開けばそのまま使えます。
スマホではブラウザのメニューから「ホーム画面に追加」すると、アプリのように全画面で起動します。

ローカルのファイルからも動きます。`index.html` をブラウザで開くだけです。ただし PWA（ホーム画面に追加・オフライン動作）を有効にするには、
HTTP(S) 経由での配信が必要です。

ローカルで動かす場合:

```bash
cd hair_karte
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

main ブランチへの push で、`.github/workflows/pages.yml` が GitHub Pages へ自動デプロイします。

## データについて

- カルテと写真は、開いたブラウザの **IndexedDB** にのみ保存されます。外部送信は一切ありません。
- そのため、**ブラウザのデータを消去すると、カルテも消えます**。
  機種変更前やデータ消去前には、設定タブから必ずエクスポートしてください。
- プライベートブラウジングでは保存されない場合があります。

js/products.js  スタイリング剤を探す（検索先リンクの組み立て）
js/app.js       ルーティング、各画面の描画、フォーム処理、集計
sw.js           オフライン用 Service Worker

## 対応ブラウザ

IndexedDB と Canvas が使える最近のブラウザ（iOS Safari / Android Chrome / デスクトップ各種）。
外部ライブラリやビルドツールは使用していません。

## デザインについて

アイコンはすべて自前の SVG（`index.html` 内のスプライト）で、絵文字は使っていません。
`currentColor` で描いているため、ライト / ダークテーマや文字色にそのまま追従します。
アプリアイコンは櫛をかたどったシンプルなロゴです。

部位図も SVG です。図・引き出し線・文字をすべて同じ SVG の座標系に置くことで、
画面幅が変わっても吹き出しの位置がずれません。入力欄を並べる代わりに図をタップして
値を選ぶ形にし、画面から文字を減らしています。長い値は図の中では省略表示になり、
全文は「伝える文章」「見せる」の画面で確認できます。
